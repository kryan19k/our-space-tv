# Code of Conduct

We want this to be a friendly, harassment-free project for everyone.

**Expected:** be respectful, assume good intent, give and accept constructive feedback, and focus on
what is best for the project and the people using it.

**Not acceptable:** harassment, insults, discrimination, publishing other people's private
information, and sustained disruption of discussions.

Maintainers may edit, hide or remove comments, issues and pull requests that break these rules, and
may block repeat offenders. To report a problem, use GitHub's private **Report content** option on
the item, or open a private security advisory if the matter is sensitive.

This statement is adapted in spirit from the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), which
applies as the fuller reference.
