# Our Space

A calm, customisable home screen for Vizio SmartCast TVs, plus a phone remote that opens it for you.
Everything is static web pages hosted on GitHub Pages. There is no server to run, no account to
create, and no app to install.

> Not affiliated with VIZIO, Inc. See [NOTICE.md](NOTICE.md).

## Why this exists

SmartCast TVs offer no setting to boot into an app of your choosing, and there is no app store for
sideloading a launcher. What the TV _does_ have is a local network API that can open a web page.
So:

```
 iPhone / Android browser                     Vizio TV (same Wi-Fi)
┌──────────────────────────┐   HTTPS :7345   ┌──────────────────────────┐
│ Phone remote (index.html)│ ──────────────► │ SmartCast API            │
│  • remote, scenes, apps  │  "open this URL"│  └─ built-in web browser ─┐│
│  • customise the TV page │                 │      loads  /tv/  ◄──────┘│
└──────────────────────────┘                 └──────────────────────────┘
          both pages are served by GitHub Pages
```

Open the remote, and your own home screen appears on the TV.

## Features

**Phone remote** (`index.html`)

- D-pad, volume, power, input switching, and a live volume slider
- One-tap **scenes** (fireplace, movie night, wind down, all off)
- App tiles with real launch IDs (YouTube, Netflix, Prime Video, Hulu, Disney+, Max, Peacock,
  Paramount+, Tubi, Crunchyroll, Plex) and a "Continue" row
- Sleep timer, Home-Screen-installable, remembers its pairing
- Opens the TV home screen automatically when the TV has just been turned on, never while something
  is playing
- Live preview and editor for the TV home screen (name, colours, backgrounds, video playlist,
  weather, widgets)

**TV home screen** (`launcher/`, built into `tv/`)

- App grid with logos, favourites and recents, drivable with a TV remote
- Looping video or built-in scenic backgrounds, with a playlist that rotates
- "At a glance" cards: weather, crypto prices, U.S. national debt (live estimate), news on topics you
  choose, and "on this day"

## Quick start

1. **Fork** this repository.
2. In your fork go to **Settings → Pages**, choose **Deploy from a branch**, branch `main`, folder
   `/ (root)`.
3. On your phone, on the same Wi-Fi as the TV, open `https://<your-username>.github.io/<repo>/`.
4. Follow the **Setup** steps: enter the TV's IP address, allow its certificate once, then pair with
   the PIN shown on the TV.
5. Turn the TV on and tap **Open Our Space**. Add the page to your Home Screen for one-tap access.

Find the TV's IP under **Menu → Network → Manual Setup** (or in your router's device list), and give
it a fixed address (DHCP reservation) so it does not change.

### Turning the TV on from the phone

A TV that is fully powered down does not answer on the network. On the TV set
**Menu → System → Power Mode → Quick Start**. Without it, the **On** button cannot reach the TV.

## Customising

| What                  | Where                                                                     |
| --------------------- | ------------------------------------------------------------------------- |
| Look, widgets, videos | **Customize** tab on the phone remote, then **Save & show on TV**         |
| News topics offered   | [`news-topics.json`](news-topics.json) (refreshed every 30 minutes)       |
| Apps on the remote    | `APPS` list in [`index.html`](index.html) (see [docs](docs/how-it-works.md)) |
| Default home screen   | [`launcher/src/lib/appearance.ts`](launcher/src/lib/appearance.ts)        |
| Background videos     | Put an H.264 MP4 in `videos/` and add its link in the Customize tab       |

Prefer an H.264 MP4 at 1080p or lower for the TV. A longer clip (10 s or more) loops more smoothly.

## Development

```bash
cd launcher
npm ci
npm run dev          # http://127.0.0.1:5173
npm run lint && npm run format:check
npm run build:site   # builds into ../tv and refreshes ../logos
```

The built `tv/` folder is committed because GitHub Pages serves it directly. Rebuild and commit it
whenever you change the launcher. The phone remote is a single dependency-free file; edit
`index.html` and reload.

```
index.html        phone remote (vanilla JS, no build step)
tv/               built TV launcher (generated, do not edit)
launcher/         TV launcher source (React, TypeScript, Vite, Tailwind)
logos/, videos/   shared assets
news-topics.json  topics for the headline job
news.json         headlines (generated by .github/workflows/news.yml)
scripts/          the headline job
docs/             how it works, API notes, troubleshooting
```

## Privacy and security

- **No server of ours.** Pages are static. Nothing is logged or collected by this project.
- **The pairing token** is stored in your phone's browser (local storage plus a one-year cookie, so
  Safari clearing site data does not unpair you). It is handed to the TV inside the page address
  _fragment_ (`#…`), which browsers never send to a web server, and the TV keeps it in its own
  browser storage. Anyone who gets the token can control the TV from your network. Treat it like a
  password: tap **Forget this TV** to remove it.
- **Local network only.** The remote talks directly to the TV's self-signed HTTPS endpoint. Nothing
  about your TV is sent over the internet.
- **Third-party requests** made by the TV page are listed in [NOTICE.md](NOTICE.md): prices, debt,
  history, weather and headlines. They receive your IP address as any website would, and the weather
  provider receives the location you type.
- **The repository is public.** Never commit tokens, IP addresses or personal calendar links. Run
  your own copy privately if you want your customisation settings kept out of view.

Report vulnerabilities as described in [SECURITY.md](SECURITY.md).

## Known limitations

- Built and tested against one TV (a V-Series 4K, `V4K55M-0804`). Other models and firmware may
  differ in app IDs and API paths. Please open an issue with what you see.
- Some app IDs come from community lists and are not verified on every firmware.
- The sleep timer runs in the phone's browser, so it only fires while the remote is open or when you
  return to it.
- Streaming apps that need DRM (Netflix, Crunchyroll and others) must be opened as TV apps. They
  will not play inside the web launcher.
- iOS may prompt again for the certificate exception if you switch between Safari and the
  Home Screen app.
